# FlowDay 🌸

Умный таск-менеджер с AI для планирования дня.

## Возможности

- **Утренний ритуал** — AI спрашивает как спала, мотивацию, что на уме → составляет мягкий план на день
- **Паттерны** — запоминает привычки и подстраивается под тебя
- **Голосовой ввод** — надиктуй задачи
- **Telegram бот** — получает утренний план и вечерний отчёт (опционально)
- **PWA** — работает как приложение на iPhone без браузера
- **Всё локально** — данные хранятся в IndexedDB, API ключ в localStorage

## Стек

- React 19 + TypeScript + Vite
- Zustand + IndexedDB (локальное хранение)
- Groq API (llama-3.3-70b)
- Tailwind CSS + Shadcn UI
- Framer Motion (анимации)
- vite-plugin-pwa

## Запуск

```bash
npm install
npm run dev
```

## Деплой

При пуше в `main` автоматически деплоится на GitHub Pages.

## Настройка

1. Открой приложение → Настройки
2. Вставь Groq API ключ (получи на [console.groq.com](https://console.groq.com/keys))
3. Опционально: настрой Telegram бота для получения уведомлений

## Установка на iPhone

1. Открой сайт в Safari
2. Нажми "Поделиться" → "На экран «Домой»"
3. Приложение откроется без интерфейса браузера
