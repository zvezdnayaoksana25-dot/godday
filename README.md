# FlowDay 🌸

Умный таск-менеджер с AI для планирования дня. Всё работает локально в браузере — никаких серверов, никаких регистраций.

---

## Что умеет

### Утренний ритуал
Каждое утро AI проводит короткий диалог:
1. **Как спала?** — оценка от 1 до 10
2. **Как мотивация?** — оценка от 1 до 10
3. **Что на уме?** — напиши или надиктуй голосом
4. **AI составляет мягкий план** — учитывает твоё состояние, паттерны и уже существующие задачи
5. **Подтверждение** — всё ок или можно попросить изменить

### Задачи
- Создание задач вручную через кнопку ➕
- Выбор даты, времени суток, приоритета и категории
- Отметка выполнения одним тапом
- Удаление задач
- Группировка по времени: утро / день / вечер

### Календарь
- Навигация по месяцам
- Точки на днях где есть задачи
- Тап на день → список задач этого дня
- Создание задач на любую дату — заранее или на сегодня

### Скорректировать день
Если планы изменились — кнопка под кругом прогресса:
- AI видит что уже выполнено ✅
- AI видит что осталось ⏳
- AI видит что было запланировано утром
- Описываешь что изменилось → AI корректирует оставшуюся часть дня

### Паттерны
AI запоминает и адаптируется:
- Средняя мотивация и сон
- Средний процент выполнения задач
- Какие категории задач чаще переносятся
- Всё это учитывается при составлении плана

### Статистика
- Процент выполнения
- Общее количество задач
- Дней с AI-планом
- Разбивка по категориям
- Паттерны и инсайты

### Telegram бот (опционально)
- Утренний план приходит в Telegram
- Вечерний отчёт тоже
- Если не настроено — приложение работает без проблем

### PWA
- Работает как приложение на iPhone
- Без интерфейса браузера
- Данные хранятся локально в IndexedDB
- Работает пока открыто приложение

## Установка

### На iPhone
1. Открой `https://zvezdnayaoksana25-dot.github.io/godday/` в Safari
2. Нажми кнопку **Поделиться** (квадрат со стрелкой вверх)
3. Прокрути вниз и выбери **«На экран „Домой"»**
4. Готово — иконка FlowDay появится на домашнем экране

### На компьютере
Просто открой ссылку в браузере (лучше всего Chrome)

## Настройка

### 1. Groq API ключ (обязательно для AI)
1. Зайди на [console.groq.com/keys](https://console.groq.com/keys)
2. Создай аккаунт (бесплатно, без карты)
3. Нажми **Create API Key**
4. Скопируй ключ (начинается с `gsk_...`)
5. В FlowDay: Настройки → AI → вставь ключ
6. Нажми **Проверить ключ** — должно быть зелёное ✓

### 2. Telegram бот (необязательно)
1. В Telegram найди **@BotFather**
2. Напиши `/newbot` и дай имя боту
3. Скопируй **Bot Token**
4. Напиши боту любое сообщение
5. Найди **@userinfobot**, напиши ему — он покажет твой **Chat ID**
6. В FlowDay: Настройки → Telegram → вставь Token и Chat ID
7. Нажми **Тест отправки**

## Как пользоваться

### Утро
1. Открой FlowDay
2. Если AI подключён — автоматически откроется утренний ритуал
3. Оцени сон и мотивацию
4. Надиктуй или напиши что хочешь сделать
5. Посмотри план → подтверди или попроси изменить
6. Задачи появятся на экране

### В течение дня
- Отмечай выполненные задачи тапом на кружок
- Добавляй новые задачи через кнопку ➕
- Если планы изменились — нажми **Скорректировать день**

### Календарь
- Листай месяцы стрелками
- Тапни на день чтобы увидеть задачи
- Кнопка **+ Задача** — создаёт задачу на выбранный день

### Вечер
- Все выполненные задачи отмечены
- Перенесённые остаются на завтра — создай их заново через календарь

## Стек

- **React 19** + **TypeScript** + **Vite**
- **Zustand** + **IndexedDB** — всё локально
- **Groq API** (llama-3.3-70b) — AI
- **Tailwind CSS** + **Shadcn UI** — дизайн
- **Framer Motion** — анимации
- **date-fns** — работа с датами
- **vite-plugin-pwa** — PWA

---

## Данные

Всё хранится **локально** в браузере (IndexedDB):
- Задачи
- Планы на дни
- Паттерны
- Настройки (включая API ключ)

Ничего не отправляется на сторонние серверы кроме запросов к Groq API для AI-функций.

### Экспорт / Импорт
Настройки → Данные → Экспорт JSON / Импорт JSON
